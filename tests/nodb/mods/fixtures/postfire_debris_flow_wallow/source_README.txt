Typically, the BARC data that is distributed on the BAER Imagery Support website is NOT field validated and should be considered a preliminary assessment of the soil burn severity.  For some fires, however, we're able to obtain a field validated, "final" version of the BARC and want to distribute this version as well as the original BARC data that was created.  For the field validated version you should refer to any directories and/or file names that include the words "FinalSoilBurnSeverity".

Feel free to contact the RSAC BAER Imagery Support Program if you have any questions.
