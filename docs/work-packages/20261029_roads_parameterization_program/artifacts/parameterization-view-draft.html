Navigation is simulated in this preview.

All overrides and resolved values must remain positive and finite in native input representation. Zero invokes native estimation and is not allowed. Tested contrasts are not calibrated ranges. The server must check every affected profile and native numeric representation.

At least one override produces a nonpositive or nonfinite value in an applicable group. Review the role-wide overrides before saving.
