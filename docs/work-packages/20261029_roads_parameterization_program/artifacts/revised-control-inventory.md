## Separate the two baselines

Production Roads uses `Roads._resolve_legacy_soil_template_path` and the single/two/three/MOFE soil writers in `wepppy/nodb/mods/roads/roads.py`. Generated `erosion_road_cap` is the retained study transformation in `builder_bridge.py`: canonical bare/forest preparation, legacy road erosion headers, and an upper-200-mm conductivity cap. It is not an existing production selectable mode. The completed r7 panel uses that conditioned baseline, not untouched generated soil. A proposed configuration UI must not silently adopt it or imply those generated results validate production templates.

Existing `tests/roads/roads_matrix.py` supplies canonical builder calls, requested/effective/emitted geometry and parsed soil/management readback, seven role orders and twelve one-factor contrasts. Reuse it for maintained tooling. Its fixed fixture geometry/management is not a full geographic preparation test. Current-project-v2/current-roads-v2 are the separate public-controller evidence. Preserve both distinctions.

## Proposed informative panel, before execution

Use current production-template fixtures first, since the first editor would preserve current production behavior. Declare width 2/4/8 m, fill length 10/30/60 m and fill slope 2/10/30% in applicable designs; categorical traffic contrasts high/low/none establish soil aliases versus actual management differences. A width-by-fill-length corner contrast in one rutted and one unrutted profile tests modeled-area/strip coupling. Do not force monotonic export: deposition and water redistribution can change directions. Include single-road negative controls for fill and RFG applicability, and an explicit alias readback for dirt/gravel.

## Findings requiring register entries

Source inspection identifies a provenance concern: `_resolve_segment_run_inputs` derives soil_texture/RFG/width `resolution_sources` from raw presence, even when invalid attributes fall back. For example WIDTH_M=999 resolves to default width but reports `segment_property`. RFG clipping and later fill-length clipping also need requested/effective reporting in the harness. Reproduction and contract-conformance classification are being recorded separately; no behavior correction is authorized by this inventory alone.

No-op and clipping cases listed above are established current semantics, not automatically defects. The static layout must distinguish unavailable controls, defaults overridden by uploaded attributes, derived geometry, native clipping and uncalibrated study ranges.
