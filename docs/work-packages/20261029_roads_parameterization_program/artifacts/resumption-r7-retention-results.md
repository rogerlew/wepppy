## Causal boundaries

Both arms use the same newly acquired, source-associated cohort and canonical
source/treatment/stack/stage APIs. All four paired final soils differ only in
FC/WP; full geometry, density, erosion, conductivity and all seven 9002 trailer
fields are unchanged within each pair. B2/B3 retain 1600 mm input depth, including
the sole changed 990–1600 mm horizon, in road/fill/buffer together. This is an
all-role policy comparison, not a buffer-only intervention.

B2/B3/B4 fresh default soil semantics reproduce frozen U12 exactly. B5's fresh
default separately changes its deep fallback FC/WP/K relative to frozen U12;
both arms share that new fallback. Its policy response is optional versus fresh
default, never a claimed exact recovery relative to the old baseline.

Native initialization observations and their source-derived layer mapping have
separate review artifacts. Exact observer-output parity permits interpretation
of those traces without attributing output differences to instrumentation.
It does not turn the rounded observations into exact internal binary32 states,
prove dynamic HK/PERC execution, supply field pore capacity, or close the whole
water budget. Raw water/sediment readback retains those limits.
