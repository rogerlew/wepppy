# Revision-4 event supply and retention comparison

Status: predeclared continuation after the rejected hydraulic factorial.
No parameter values, native code, production inputs or acceptance thresholds change.

## Question and controls

The hydraulic factorial leaves 35 of 43 small-reference misses in every cell.
Some legacy-soil controls previously retained more incoming sediment yet exported
less than generated soils; therefore excess fill erodibility alone is not a
sufficient explanation. Those older controls used revision 3, so first remove
that engine confound.

Rerun all 116 existing whole-legacy-soil diagnostic cases on the exact released
revision-4 watershed binary. Copy their original model inputs byte-for-byte,
including the original legacy soil format; explicitly retain the auxiliary
reference soil and fresh execution logs. Verify every non-soil input against the
matching accepted U12 generated case. Use the same 96 original misses and 20
passing controls, five climates, seven development materials and complete periods.
Do not translate formats, mix legacy roles into generated profiles, change runtime
settings or inspect the six withheld materials. This is a whole-profile diagnostic,
not a proposed generated-soil parameterization or proof of role equivalence.

Require an actual one-case native/runtime/accounting/particle preflight before
the broad pool. Bind exact scripts, dependencies, inputs and outputs. Retain every
failure, reparse outputs and audit all events; unexplained particle findings remain
explicit. Compare against the old legacy run to quantify engine effects and against
modern U12 to isolate the combined soil-profile treatment at a fixed engine.

## Event accounting and decision

For all selected cases, assemble paired daily/event ledgers at each road, fill
and buffer boundary: surface/lateral water, sediment inflow/outflow, net OFE
exchange, event duration and concentration where the published output supports
them. Keep native units and area bases explicit. A net boundary difference is
not a tagged particle origin, and a spatial net value cannot reveal simultaneous
local erosion and deposition. Use paved cases as zero-road-sediment controls
only after their actual outputs confirm zero road export.

Compare event support and delivery fractions before selecting source-observation
seeds. Bound any internal observation to predeclared cases and require exact
ordinary-output parity. Do not infer a physical coefficient from a selected
ratio or compensate for a suspected model defect with parameter tuning. The
next decision is which process or input assumption needs a controlled test,
not automatic advancement to a broad parameter candidate or the UI.

The full application suite remains a separate release handoff gate and may run
concurrently with these isolated native diagnostics. UI design remains human gated.
