## Design, role and response interpretation

The profile panel contains 40 production-template cases: ten paired arms in each
of H (higher export), L (lower export), P (physical passing reference) and U
(unrutted three-OFE). Passing means current physical/accounting predicates, not
legacy agreement or empirical validation. Seven additional G cases retain a
compatible generated-material underprediction context, including exact replay,
a separate canonical writer bridge, and five geometry contrasts. All 47 have
distinct actual slope/soil/management/climate signatures. The bridge's aspect
100-to-180 and serialization changes are separated from geometry sensitivity.
No reserved materials were used, and no broad fitting sweep or legacy rescue was
performed. Generated `erosion_road_cap` remains a conditioned research policy.

The [research-role disposition](revised-research-role-disposition.md) is accepted:
retained benchmark outunrut uses internally consistent ROAD/FILL/FOREST roles and
geometry. The incompatible operation was a blind transplant into the different
canonical unrutted topology; no defect in the retained research seed/helper was
established. Historical classifications remain intact.

Twelve preparation probes establish four inslope fill-length no-ops by exact input
identity. Low-to-none traffic retains soil coefficients but changes management;
it is not an input alias. Those probes are preparation evidence, not extra native
runs. The mixed surface panel does not isolate a paired surface effect.

Width mostly scales whole road/fill/buffer strip footprint and extensive export/
runoff. It is not solely a road-prism erosion coefficient. Fill length changes
area and process extent; opposite density responses occur across contexts. In the
project study, width 4-to-8 m approximately doubles export from 9,025.42 to
18,050.82 kg/year while density remains about 0.84054 kg/m²/year. Fill 30-to-60 m
at width 4 m raises export to 9,394.05 but lowers density to 0.62888. These are
original profile exports, not routed watershed outlet or road-only detachment.

Traffic is demonstrably nonmonotonic: H high/low/none gives 15.7502/4.90954/36.7819
kg/year, while L gives 2.18050/0.828163/0.103512. Management/residue differences
are part of the coupled category. The evidence cannot recommend more traffic as
erosion mitigation. Width-by-fill extensive interactions include multiplication
of footprint; near-zero density interactions do not establish a new mechanism.

The controller study exercises four geometry contexts through prepare/run, with
35 profiles and one watershed per context (144 native calls), unchanged source
soil/management/climate and 520 invariant runtime files per context. All 3,537
source entries and 907 baseline files per context were preserved. Four distinct
slopes per profile confirm actual geometry propagation. Explicit feature controls
retain precedence over fallback changes. Invalid/nonfinite resolver checks are
separate conformance evidence, not invalid uploaded/native trials.

exact current binary32 normalization residual plus serialization explains that

or relax the auditor. No native correction is warranted for that explained case.

R11's G metric difference is also explained without changing native output.
Exact replay's historical LOSS mean is 0.08712 kg/year, ELEMENT terminal total is
0.0853875, and current PASS EVENT export is 0.06868372463125. The positive terminal
NO EVENT day (year 8, May 9) contributes printed SedLeave 0.067 kg/m × width
3.96 m / 16 years = 0.0165825 kg/year. EVENT-supported ELEMENT is therefore
0.068805. Its difference from PASS, 0.000121275369, is within the single ELEMENT
F8.3 half-unit, 0.00012375. LOSS minus ELEMENT, 0.0017325, is within the annual
LOSS F12.3 half-unit, 0.00198. These are independent format bounds, not fitted
new tolerances.

The bound native `wshpas.for` publishes EVENT particle payload at terminal runoff
at least 0.001 m. Positive terminal NO EVENT/SUBEVENT sediment can exist without
that payload; strict EVENT composition checks do not certify it. The
[machine summary](revised-sensitivity-summary.json) retains all 47 LOSS, PASS,
ELEMENT and positive non-EVENT totals, rather than replacing historical values
with the current reporter. This quantified support/precision reconciliation closes
the unexplained exact-G discrepancy; it is not a blanket mass-closure claim for
all profiles or a redesign of native/report formats.

## Failures, corrections and bounded proposal

Failed wrappers, dependency stops, abbreviated LOSS reader assumptions, calendar
context failures and original comparator failures remain retained. Additive
project continuation bound the first result and helper-only dependency change.
Source inspection established `chntyp.txt` as a generated write-only contributing
area diagnostic; excluding only that file from input invariance did not exclude
it from artifact hashes. No successful project native call was rerun.

The G failure was an ancestor CLI calendar mismatch in postprocessing despite
bit-exact native output. New recovered roots preserve the old failed tree, reuse
exact inputs/outputs, and bind the actual years 1–16 calendar. The maintained
harness now checks selected reader context, native CLI and cached full calendars;
[calendar QA](revised-calendar-context-quality-review.md) retains real-filesystem
regressions. This guard was checked retrospectively for all 47 and before the
last six calls; it was not present during the first 41. No precision bound or
expected response direction was weakened to obtain passing results.

The proposed [settings contract](../../../schemas/roads-settings-contract.md) and
[ADR-0135](../../../adrs/ADR-0135-roads-settings-controls.md) have scientifically
appropriate claims: five existing fallbacks, preserved feature precedence,
whole-strip width effects, design-specific fill applicability, coupled traffic/
surface categories, explicit provenance and no generated-soil adoption. The
existing surface choice has source/consumer support but no isolated surface
sensitivity claim from this panel. Numeric validity limits, tested contrasts and
field-calibrated ranges remain distinct. Neither default nor custom settings are
calibrated by this work. Final result citations and scope qualifications were integrated and independently
rechecked before human review; the exact reviewed versions are recorded below.

No additional scientific finding blocks presenting this bounded proposal for
human review. Actual browser/persistence/native/report workflow and invalid,
readonly, fork/restore states remain future implementation acceptance work after
the explicit human specification/layout gate.
