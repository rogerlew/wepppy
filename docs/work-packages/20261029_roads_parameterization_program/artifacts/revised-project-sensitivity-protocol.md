and fill value equals the saved request, with roads_default provenance. The pair
must preserve all unrelated inputs; slope width and fill lengths differ by design.

persisted state before preparation. Run prepare_segments and run_roads_wepp.
Require absent current admission after prepare and valid admission only after fresh
completion. Read every completed manifest row, slope geometry, management/soil
hashes and WAT native-consumed areas. Verify native complete calendars and retained
execution context. Reuse canonical inspect_outputs for daily area/water accounting;
read current segment summaries and totalwatsed for mean annual and event sediment
and water responses. Retain the entire current outputs rather than a scalar score.

Compare width-only, fill-only and their interaction (joint-minus-both-main-effects)
for reported sediment export and hydrology, with modeled area stated. Expected
direction is a hypothesis; no monotonic pass requirement or legacy-score target.
Retain input aliases, no-op findings, failed attempts and clipping explicitly.
Require original source and each clone baseline inventory unchanged after each
context. Independent outcome review is required before claiming this lane complete.

and resolves them with width/fill defaults 8/60. Compare against defaults 4/30:
valid explicit properties must retain their original values; absent attributes
may respond. Report counts and exact requested/effective/source rows. This control
performs no native call and does not claim saved-state production override behavior.

under both default pairs, since the source upload may contain no explicit width
