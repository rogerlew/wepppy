      denial, health, container identities, cleanup and rollback readiness.
- [ ] CDP/assertion/log/artifact handling cannot print or persist a raw JWT,
      protocol header, password, cookie or signing material.
- [ ] Tests do not add a public bypass, test-only production route or shared
