## Residual quality risks

`raster_summary` materializes the full masked raster, compressed values and finite
mask. Ordinary Ron projects permit dimensions up to 8192 pixels per side; the
962-cell baseline cannot bound large-project memory or latency. Measure a
representative large ordinary DEM before broader rollout. This is a cost risk,
not a demonstrated failure or justification for a new processing architecture.

The lifecycle test's conditional fault matrix is useful at this size. Keep shared
setup explicit and split cases if future additions require substantially different
execution or assertions. Avoid converting it into a general fault-injection
framework. `_extract_runid` in `rq/exception_logging.py` is now unused and is a
small optional cleanup.
