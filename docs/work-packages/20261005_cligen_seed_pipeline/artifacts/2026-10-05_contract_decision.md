## Exact normative delta

Climate Options gains an optional advanced `cligen_seed` field. The request
contract accepts an integer in `0..99999`, persists it as `_cligen_seed`, and
requires an explicit value to reach every applicable CLIGEN subprocess as
`-r<seed>`. Omission preserves stored state; an empty submitted field selects
automatic behavior. Malformed values fail transactionally before enqueue.

No other climate parameter, mode, default, queue edge, authorization rule, or
CLIGEN algorithm changes. Implementation conformance is pending.

## Compatibility and data impact

The persisted attribute already exists and legacy objects may contain either
`None` or an integer generated by current modified-climate paths. No migration
is required. Existing clients that omit the key retain stored state. Blank UI
state retains automatic behavior. Explicit seeds opt into deterministic native
seeding and can intentionally change generated climate values.

`ClimateMultipleBuildInputs` must include the seed because it determines output;
a concurrent change must supersede rather than publish stale work. Batch climate
resynchronization continues treating generated leaf seeds as runtime state
unless the separate batch policy explicitly promotes user configuration.

## Valid-state matrix

| Request state | Persisted state | Required result |
| --- | --- | --- |
| Key absent | absent/`None`/integer | Preserve stored value |
| Key present, empty | any valid state | Persist `None`; use existing automatic behavior |
| Integer/string integer `0..99999` | any valid state | Persist integer and forward exactly |
| Boolean, fraction, text, negative, or `>99999` | any state | Validation error and no partial mutation |
| Legacy NoDb missing attribute | N/A | Read as `None`; next normal write may materialize it |

## Security impact

Low. The bounded integer is appended as one argv element without shell parsing.
Existing authorization, CSRF/JWT, run containment, locks, and queue topology are
unchanged.

## Required regression evidence

- Template and controller payload tests for blank and explicit values.
- Route tests proving valid persistence and invalid rollback before enqueue.
- NoDb disk reload through the normal reader.
- RQ metadata replay retaining the exact seed.
- Unit matrix for all Climate-to-CLIGEN adapters and multiple-build snapshot
  supersession.
- Direct real-binary test proving `-rN` appears in the consumed command and two
  identical seeded builds produce byte-identical parseable `.cli` output.
- Bounded `canine-liar` validation with pre-mutation backup and exact restore of
  unrelated state.
