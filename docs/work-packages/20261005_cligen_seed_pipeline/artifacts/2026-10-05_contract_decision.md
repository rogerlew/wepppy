## Exact normative delta

Climate Options gains an optional advanced `cligen_seed` field. The request
contract accepts an integer in `0..99999`, persists it as
`_cligen_seed_override`, and
requires an explicit value to reach every applicable CLIGEN subprocess as
`-r<seed>`. Omission preserves stored state; an empty submitted field selects
automatic behavior. Malformed values fail transactionally before enqueue.

The existing `_cligen_seed` remains automatic/runtime state. No other climate
parameter, mode, default, queue edge, authorization rule, or CLIGEN algorithm
changes. Implementation conformance is pending.

## Compatibility and data impact

The explicit override attribute is additive. Legacy objects may contain
`_cligen_seed` values generated by current modified-climate paths; those values
remain runtime state and are never treated as explicit. No migration is
required. Existing clients that omit the key retain any explicit override.
Blank UI state clears the override and retains current path-specific automatic
behavior. Explicit seeds intentionally change generated climate values.

`ClimateMultipleBuildInputs` must include the override because it determines output;
a concurrent change must supersede rather than publish stale work. Batch climate
resynchronization copies `_cligen_seed_override` as configuration while
continuing to treat generated leaf `_cligen_seed` values as runtime state.

## Valid-state matrix

| Request state | Persisted state | Required result |
| --- | --- | --- |
| Key absent | override absent/`None`/integer | Preserve override |
| Key present, empty | any valid state | Persist `None`; use existing automatic behavior |
| Integer/string integer `0..99999` | any valid state | Persist integer and forward exactly |
| Boolean, fraction, text, negative, or `>99999` | any state | Validation error and no partial mutation |
| Legacy NoDb missing override | generated `_cligen_seed` absent/`None`/integer | Override is `None`; generated state remains runtime-only |
| Malformed durable override | any | Fail before CLIGEN with actionable error |

## Security impact

Low. The bounded integer is appended as one argv element without shell parsing.
Existing authorization, CSRF/JWT, run containment, locks, and queue topology are
unchanged.
