The 45-year replay independently compares genuine differing measurements for a two-ID subset. Local verification covers the original hill count and original duration in separate experiments. All six family group counts and identity counts matched the table above. Both manifest checks accepted each layout, and deep validation rejected an incorrect physical PASS count.

I also passed the six source points from the failing `hill_14.slp` test into the incumbent and replacement native segmenters with a target length of 25 and buffering disabled.
