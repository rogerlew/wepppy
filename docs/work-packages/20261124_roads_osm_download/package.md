# Download OpenStreetMap roads for a project

Provide a reusable GIS download and editable input for Roads. Hydroenforcement shares the expanded default selection of mapped vehicular roads. Existing project input remains user-owned. Delivery includes Roads end-user instructions, an independent usability review, desktop and narrow screenshots and round-trip evidence. The [download contract](../../schemas/roads-osm-download-contract.md) governs the feature. Security impact is high for a new run-scoped endpoint reaching an external service. Retain a dedicated review.

Local implementation and review are complete. See the [completed plan](prompts/completed/implementation.md) and [execution tracker](tracker.md).
