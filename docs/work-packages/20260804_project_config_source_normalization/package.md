# Project Configuration Source Normalization (WP00B)

**Status**: Closed (2026-08-05)
**Security impact**: `low`
**Initiative branch**: `feature/project-owned-config`
**Canonical branch**: `master`

## Overview

WP00B defines the canonical typed scalar/list encodings and deterministic byte
serializer required before project-owned config writers can exist. It
normalizes the shared default and 128 active named presets while preserving
their typed values. It does not enable or wire a project writer.

## Scope

Included work covers the 129 active/default source files, 3,341 assignments,
the typed parser and canonical serializer, source normalization/check tooling,
golden bytes, ambiguity rejection, semantic-parity evidence, tests, and
documentation.

Legacy pseudo-TOML snapshots under `configs/legacy` remain byte-unchanged. They
are compatibility inputs, not sources used by the future resolver. WP01 retains
their reader compatibility. Registry composition and writer wiring remain WP03
and WP04.

## Canonical Type Encodings

| Type | Canonical encoding |
| --- | --- |
| null | `None` |
| boolean | lowercase `true` or `false` |
| integer | base-10 `str(int)` with no redundant sign or leading zero |
| finite float | Python shortest round-trip `repr(float)`, retaining `.0` |
| string | UTF-8 JSON double-quoted string with compact escaping |
| scalar list | `[item, item]`; strings/null/numbers as above and booleans as Python-literal `True`/`False` for current `ast.literal_eval` compatibility |

Nested lists, tuples, mappings, multiline strings, non-finite floats,
no-value options, unquoted strings, inline value comments, interpolation,
duplicate names, and case-only collisions are rejected.

## Compatibility and Regression Plan

Before/after source maps are parsed with the accepted legacy lexical decoder
and compared as typed values for every section and option. This proves that
quote, boolean-case, list-comma, whitespace, and comment-placement edits do not
change runtime meaning. Existing NoDb accessor tests and the focused serializer
suite then exercise the current reader boundary. Generated byte evidence uses
a checked-in golden fixture and two differently ordered maps.
