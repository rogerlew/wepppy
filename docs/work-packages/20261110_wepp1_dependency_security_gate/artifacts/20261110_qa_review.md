# QA review - wepp1 common-image dependency security gate

## Metadata

- **Reviewer**: unassigned; independent reviewer required
- **Date**: pending
- **Implementation revision**: pending
- **Gate status**: fail until implementation and validation are reviewed

## Review Scope

Review reproducibility, maintainability, test quality, report/policy fixtures,
workflow generation, clean image builds, test-image identity, and evidence
retention. Security exploitability decisions remain with the security reviewer;
valid user behavior remains with the correctness reviewer.

## Required Checks

- [ ] Tool and advisory-database versions are reproducible and pinned.
- [ ] Raw reports are machine-readable, immutable for one image, and hashed.
- [ ] Policy fixtures cover clean, blocking, duplicate, exception, expired,
      malformed, missing, stale, and image-mismatch cases.
- [ ] CI edits are made in `.github/forest_workflows/` when generated workflow
      rules apply, and generated outputs pass the builder `--check` gate.
- [ ] Test/build commands use canonical `wctl` and Docker entry points.
- [ ] No logs or artifacts contain credentials, environment secrets, private run
      identifiers, `/wc1` contents, or Docker registry tokens.
- [ ] Focused tests identify the causal dependency boundary before broad gates.
- [ ] Full pytest, npm lint, and full npm tests pass on the final candidate.
- [ ] Validation records exact commands, revisions, image IDs, counts, durations,
      exit statuses, and limitations.
- [ ] Rollback and rerun instructions are safe and idempotent.
