## Findings

1. **High — native RQ pool arguments were discarded; closed in `db7ef7cb7`.**
   The initial `Connection.__init__(**_rq_defaults)` always
   rebuilt from environment. Installed RQ's `worker_pool.run_worker` and
   `scheduler` reconstruct this class with `connection_pool`; additionally
   `wepppy/rq/webhook_hooks.py:_bounded_connection` passes a pool with short
   timeouts and disabled retries. Discarding it removed the hook's latency bound.
   The revised `wepppy/config/rq_redis.py` uses an identity marker only for RQ
   config construction and forwards native arguments otherwise. The retained
   subprocess regression bypasses the pytest Redis recorder and proves native
   pool identity and timeout preservation. The private installed-CLI receipt
   proves explicit empty `--url` suppresses the environment URL.

2. **Medium — dev/HPC healthchecks did not require PONG; closed in `db7ef7cb7`.**
   A `redis-cli` Redis error response can
   leave the process successful without a PONG. Both changed dev/HPC checks now
   use `grep -qx PONG`, matching prod/canary. Private runtime receipts prove a wrong credential fails the PONG gate and a missing
   probe credential fails explicitly. Seven Compose variants render and scan.

3. **Medium — password framing differed across shell and native clients;
   closed in `db7ef7cb7`.** Initial shell
   `[[:space:]]` accepted leading/trailing UTF-8 nonbreaking spaces rejected by
   Python/Go. The revised shell validates decoded codepoints and Go includes
   Python's additional U+001C–U+001F whitespace characters. Re-review directly
   exercised 65 shell/Python synthetic cases: leading/trailing Python whitespace
   codepoints below U+3100, valid multibyte/interior whitespace, LF terminators,
   invalid/truncated UTF-8, NUL, empty and embedded LF. Zero acceptance mismatches
   remained. Retained shell/Python framing cases cover Unicode boundaries and
   malformed UTF-8; both Go service config suites cover the matching framing policy.
   Dashboard uses the same Python byte/framing rule and passes actual AUTH.

4. **Medium — password string subclasses leaked under format specifications;
   closed in `db7ef7cb7`.** Both `_Password` classes now
   override `__format__`. Re-review confirmed five native wrapper formatting
   cases (repr, str, empty format, `:s` and alignment) contain no synthetic canary,
   while `.encode()` preserves the original bytes. The format-spec regression is retained; actual client/dashboard AUTH
   receipts prove the wrappers preserve Redis encoding.
