An offshore or outside point fails explicitly, even with nearby observations. A fully missing band fails for that month. Empty, missing and malformed products fail as provider errors. Nonfinite request coordinates fail before interpolation. Legacy scaled and raw sentinel values and newly generated standard NoData values are supported. Explicit non-cubic and unrelated datasets keep existing behavior.

Required evidence includes real synthetic-raster metquery requests for cubic parity, weighted coastal masks, edges, offshore and missing band failures, malformed coordinates and assets, an unaffected legacy method control, a mixed-day preprocessing round trip, and the original station artifact via the candidate metquery and CLIGEN client. ## Independent review disposition

Both independent read-only reviewers found that partially missing daily source records were aggregated with their masks lost. The January legacy rainfall band contains 36,782 negative cells after excluding both sentinels. Temperature contamination can pass physical bounds. The contract now screens physically impossible source values before interpolation, separates invalid output from unavailable coverage, and records the legacy risk and need for a future validated raster rebuild. It defines the GET and POST error order and the unchanged ranking-view failure envelope. The forest endpoint override is opt-in, and worker identity and provider selection are required evidence. The synthetic preprocessing regression uses mixed valid and missing dates so a masked-array stacking regression fails the test.

A complete valid inland stencil near 41.5498502 E, 64.0498689 N reproduced an existing cubic undershoot of -0.259 mm/day for January. The contract retains the existing result and CLIGEN dry-month handling for this case. Such a result cannot establish that the source cells were missing. Retain the real control and a synthetic undershoot control.
