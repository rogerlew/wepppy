Starting revision `d36c94c4a`. The operator explicitly requested that deprecation be a warning and asked to continue the recovery. It does not expose or enable new generated-storm or batch authoring, supply missing climate inputs, alter native parameters, or reinterpret a stale upload mode. The latter requires the climate publication fix.

Continuous modes and new-authoring capability rules are unchanged. Deprecation is never itself an execution error. There is no change to run authorization or trust boundaries. Security impact is low.
